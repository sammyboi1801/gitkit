# GitKit

A VS Code extension that makes everyday git and GitHub work visual, without getting in the way.

- **Pulse:** your repo's state at a glance, with suggested next actions
- **Workflow Studio:** build GitHub Actions workflows visually, with YAML that stays in sync
- **Branch Map:** a clean commit graph; drag one branch onto another to merge or rebase
- **Recipes:** your own multi-step git workflows, run as a sequence of steps
- **Undo timeline:** step back through recent git operations, using the reflog

Every action previews the exact `git` command it will run.
